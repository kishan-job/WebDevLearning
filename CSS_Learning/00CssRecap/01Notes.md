# Box model
1. Body takes by default takes the heigh of the viewport.
2. Every elemnt in the html takes the height of the content.

## Pading 
- Padding property is the space given around the content of the element.

## Border
- Border property  define the boundaries around an HTML element, providing a visible outline.

## Margin
- Margin property divides the two elements. Margin property is not included in the size of the element boxsize.
- If we give marging betweeen element A(M-40px) and element B(M-60) then the margin between the two elements would be the heights vaule which is M-60px not the 100px

## box-sizing
- Box-sizing property with border-box The width and height properties (and min/max properties) include the padding and border, but not the margin.

- By default box-sizing is content-box where the width and height properties (and min/max properties) include only the content, but not the padding, border, or margin.

# Abosulte Units
Absolute units have a fixed size

 ## pixel:
 - A pixel is a unit of length representing a single dot on the screen.
 - 1 inch is 96 px
# Relative Units
Relative units are based on the size of other elements or the viewport, making them more flexible and responsive.

## rem:
- 1 rem is 16px

- The rem unit is relative to the font-size of the root element (<html>).

## em:

- The em unit is relative to the font-size of the element itself. If used on the root element, it is relative to the root font-size.

## Percentages

- Percentages are relative to the parent element's dimensions.


# vh
- vw units are relative to 1% of the viewport's width.

# vh
- vh units are relative to 1% of the viewport's height.
